# プロダクト要求定義書

## プロダクトビジョンと目的

Oracle データベースに対するアプリケーションの動作テストを支援するツール。
対象テーブルへの INSERT / UPDATE / DELETE 操作をトリガーによってログテーブルへ記録し、その変更履歴を Excel形式で出力することで、テスターが DB の変更内容を手軽に確認できるようにする。

## ターゲットユーザーと課題・ニーズ

### ターゲットユーザー

- Oracle DB を使うシステムの開発者・テスター

### 課題・ニーズ

- アプリケーションが DB をどう更新したかを手動で SELECT するのは手間がかかる
- テスト証跡として変更ログを残したい
- 非エンジニアでも GUI 操作で利用できる手軽なツールが欲しい

## 主要な機能一覧

| # | 機能 | 概要 |
|---|------|------|
| 1 | トリガー作成 | 監視対象テーブルに対してログ取得用のトリガー・ログテーブル・シーケンスを生成する |
| 2 | ログ取得 | INSERT / UPDATE / DELETE の発生を検知し、変更前後の値をログテーブルへ記録する |
| 3 | Excel 出力 | ログテーブルの内容を .xlsx 形式で出力する |
| 4 | ログ削除 | 取得済みのログレコードを削除する |
| 5 | オブジェクト削除（Drop） | テスト終了後にトリガー・ログテーブル・シーケンスを DROP する |

## 成功の定義

- テスターが GUI を操作するだけで、テーブルの変更履歴を Excel で取得できる
- テスト後にオブジェクトを手軽にクリーンアップできる
- ツール起動から出力まで 5 分以内に完了できる

## ビジネス要件

- スタンドアロン（JAR + バッチファイル）で配布でき、追加インストール不要で動作すること
- Oracle 11g 以降に対応すること
- Java 8 以降で動作すること

## ユーザーストーリー

1. テスターとして、テスト対象テーブル名を入力して「Create」を押すと、ログ取得の準備が整うことを期待する
2. テスターとして、テスト対象アプリを操作した後に「Print」を押すと、変更履歴が Excel で得られることを期待する
3. テスターとして、テスト終了後に「Drop」を押すと、作成したオブジェクトが削除されることを期待する

## 受け入れ条件

- Create 後、指定テーブルへの INSERT / UPDATE / DELETE がログテーブルに記録されること
- Print 後、ログの内容が正しく Excel に出力されること
- Drop 後、トリガー・ログテーブル・シーケンスがすべて削除されること

## 機能要件

- GUI は Java Swing で実装する
- 複数テーブルの同時監視に対応する

## 非機能要件

- Oracle DB へは JDBC 接続（ojdbc8）で行う
- 文字コード設定に対応する（DB 側の文字コードを properties で指定可能）
- Excel 出力には Apache POI を使用する
