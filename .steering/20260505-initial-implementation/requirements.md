# 要求内容（初回実装）

## 概要

Oracle DB を対象とした CRUD テストサポートツールの初回実装。
テーブルへの INSERT / UPDATE / DELETE 操作をトリガーで自動記録し、変更履歴を Excel 形式で出力する。

## ユーザーストーリー

1. テスターとして、監視したいテーブル名を入力して「Create」を押すと、ログ取得の準備が自動で整う
2. テスターとして、テスト対象アプリを操作した後に「Print」を押すと、変更履歴が Excel ファイルとして得られる
3. テスターとして、テスト終了後に「Drop」を押すと、作成したすべての DB オブジェクトが削除される
4. テスターとして、「Delete Log」を押すと、蓄積されたログレコードだけを削除できる

## 受け入れ条件

- [ ] Java 8 + Oracle 11g 以降の環境で動作すること
- [ ] GUI は Java Swing で実装し、追加インストール不要のスタンドアロンで動作すること
- [ ] Create 後、指定テーブルへの INSERT / UPDATE / DELETE がログテーブルに記録されること
- [ ] Print 後、ログの内容が .xlsx 形式で正しく出力されること
- [ ] UPDATE は変更前（OLD）・変更後（NEW）を隣列に並べて出力し、変更セルを黄色でハイライトすること
- [ ] Drop 後、トリガー・ログテーブル・シーケンス・管理テーブルがすべて削除されること
- [ ] 複数テーブルの同時監視に対応すること
- [ ] start.bat の環境変数を変更するだけで DB 接続先を切り替えられること

## 制約事項

- DB ドライバは Oracle JDBC（ojdbc8）を使用する
- Excel 出力は Apache POI を使用する
- ヒープサイズは `-Xmx64M` を基準とする
- Java 9 以降の機能は使用しない
